ফিতরাহ অ্যাপের জন্য ম্যানুয়াল টেস্টিং টাস্ক লিস্ট
তারিখ: ১৯ এপ্রিল ২০২৬

========================================
A) রিগ্রেশন চেক (আগে ফিক্স হয়েছে — আবার ভেরিফাই করতে হবে)
========================================

1) শর্টস ইনফিনিট স্ক্রল নেভিগেশন
- একটি শর্টস খুলে একের পর এক স্ক্রল করুন।
- নিশ্চিত করুন ১-২ বার স্ক্রলেই হোমে রিডাইরেক্ট না হয়।
- প্রত্যাশিত ফল: স্মুথ স্ক্রল, অযথা রিডাইরেক্ট নয়।

2) Add Video পেজ থেকে নরমাল YouTube ভিডিও যোগ
- একটি ভিডিও URL যোগ করুন।
- অ্যাপ রিফ্রেশ করে হোমে ফিরে দেখুন।
- প্রত্যাশিত ফল: ভিডিও সেভ থাকবে এবং UI-তে দেখা যাবে।

3) Add Video পেজ থেকে YouTube Shorts যোগ
- একটি Shorts URL যোগ করুন।
- রিফ্রেশ/রিওপেন করে যাচাই করুন।
- প্রত্যাশিত ফল: শর্টস সেভ থাকবে এবং লিস্টে দেখা যাবে।

4) Share Target (ভ্যালিড URL)
- অন্য অ্যাপ থেকে YouTube ভিডিও ও Shorts URL শেয়ার করুন।
- প্রত্যাশিত ফল: সঠিকভাবে পার্স হয়ে অ্যাপে যোগ হবে।

5) ভিডিও কাউন্ট ও UI রেন্ডার মিল
- ডাটাবেসে মোট আইটেম বনাম UI-তে মোট আইটেম মিলিয়ে দেখুন।
- প্রত্যাশিত ফল: UI-তে কোনো আইটেম মিসিং থাকবে না।

6) ব্র্যান্ডিং কনসিস্টেন্সি
- পেজ টাইটেল, ইনস্টল প্রম্পট, অ্যাপ নেম চেক করুন।
- প্রত্যাশিত ফল: সব জায়গায় “Fitrah” থাকবে।

7) Consecutive Shorts limit আচরণ
- সেটিংস থেকে limit সেট করুন।
- একাধিক নতুন shorts session শুরু করে দেখুন।
- প্রত্যাশিত ফল: limit শুধু নতুন session শুরুর ক্ষেত্রে কাজ করবে, প্রতিটি swipe-এ নয়।


========================================
B) হাই-প্রায়োরিটি বাগ হান্ট (সম্ভবত এখনো ফিক্স লাগবে)
========================================

1) Signup flow stability (P0)
- নতুন অ্যাকাউন্ট দিয়ে signup করুন (confirm password সহ)।
- Chromium / Safari / Firefox এ সম্ভব হলে রিপিট করুন।
- প্রত্যাশিত ফল: ক্র্যাশ ছাড়া অ্যাকাউন্ট তৈরি ও রিডাইরেক্ট।
- রিস্ক: signup-এ browser/page crash হওয়ার ইতিহাস আছে।

2) Login + session cookie persistence (P1)
- লগইন করে রিফ্রেশ দিন, protected page খুলুন, তারপর sign out করুন।
- প্রত্যাশিত ফল: রিফ্রেশের পরেও session valid; signout-এ session clear।

3) Fresh signup এর পর auth-dependent action (P1)
- signup শেষে সাথে সাথে: ভিডিও যোগ, settings save, share-target ব্যবহার।
- প্রত্যাশিত ফল: auth state race condition ছাড়া সব কাজ করবে।

4) Invalid shared URL handling (P2)
- malformed URL ও non-YouTube URL শেয়ার করুন।
- প্রত্যাশিত ফল: graceful error message; crash নয়; ভুল ডাটা save নয়।
